Add Service user to all found Teams.
If fail, leave a list of the team ids that failed to add in the export directory

https://developers.asana.com/reference/adduserforteam

postman request POST 'https://app.asana.com/api/1.0/teams/{{team_gid}}/addUser' \
  --header 'Content-Type: application/json' \
  --body '{
  "data": {
    "resource_type": "team_membership",
    "user": {
      "gid": "{{user_gid}}"
    },
    "is_guest": false,
    "is_limited_access": false,
    "is_admin": true
  }
}'
